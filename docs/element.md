# Element — ORBITAL 지구본

`anydesign` element mode / hybrid / 2026-10-23

## Source & target

사용자 첨부 이미지 #1(665×557), #2(632×521)의 지구본 패널이다. 목표는 기존 ORBITAL의 지구본을 이 시각 방향으로 재구성하는 것이다. 두 화면은 서로 다른 대륙이 보이는 참고 이미지이며, 실제 회전 애니메이션을 관찰한 것은 아니다.

## 1. What this element is

짙은 남색 관제 화면에서 실제 지형이 입체적으로 보이는 지구를 크게 배치한다. 푸른 대기광과 주황색 거점의 대비가 핵심이다. 사진 지형은 래스터 텍스처, 회전·선택·라벨은 코드로 구성하는 hybrid가 적합하다. 정적인 지구 이미지로 대체하면 자유로운 회전과 국가 선택을 구현하기 어렵다.

## 2. Spec

구조: 패널 헤더 → 장면(WebGL 지구, Canvas 장식·선택 윤곽, HTML 거점 버튼) → 안내와 컨트롤 → 기존 분야 버튼.

이미지에서 관찰한 상태는 주황색 활성 거점과 강조된 유럽 라벨이다. hover·focus·오류 상태는 이미지에서 확인할 수 없으므로 구현에서 정의했다. 뒷면 거점 숨김과 라벨 충돌 회피는 회전 사용성을 위한 구현 결정이다. 모바일 원본은 제공되지 않아 라벨 수 축소와 높이 조정은 재구성 제안이다.

상단의 `ORBITAL VIEW / EARTH`, `3D EARTH VIEW`만 대문자와 넓은 자간을 사용한다. 국가명은 원래 한글 표기와 보통 자간을 유지한다. 제목·라벨은 약 600을 기준으로 삼고 굵은 대형 글씨로 지구를 가리지 않는다.

## 3. Reconstruction prompt

기존 React/TypeScript ORBITAL에서 지구본만 수정한다. #0C131D 패널에 사진 지형, 도시 불빛, 흰 구름을 가진 직교 투영 구면을 렌더링하고 가장자리에는 얇은 푸른 대기광을 준다. #FE984D 거점에 밝은 테두리와 작은 glow를 적용한다. 한글 국가명 11px/600, 보조문구 9px의 #1D2737 반투명 라벨을 겹치지 않게 배치한다. 기존 분야 필터 콜백을 연결하고 드래그·방향키 회전, 일시정지·확대·축소·초기화를 지원한다. 뒷면 거점은 숨긴다. 숫자는 실제 분야 집계임을 밝히고 국가별 기사 수로 오인하게 만들지 않는다. 구름·도시 불빛은 정적 텍스처이며 조명은 연출이다. 격자, 큰 영문 국가명, 단색 대륙, 강한 네온은 사용하지 않는다.

## 4. Generative image prompt

이번 구현은 검증 가능한 위경도 정합성을 위해 로컬 지구 텍스처를 사용한다. 이미지 생성은 실행하지 않았다. 아래는 정적인 목업 이미지가 별도로 필요할 경우에만 쓰는 참고 프롬프트다.

SUBJECT: 한 개의 실제 지구, 아시아와 극지방의 얼음, 흰 구름과 미세한 야간 도시 불빛.
STYLE / MEDIUM: 사실적인 위성 지형 기반의 구체 렌더.
COMPOSITION & CAMERA: 직교 투영, 중앙 정렬, 지구 주위 충분한 여백.
LIGHTING: 왼쪽 위에서 부드러운 빛, 오른쪽 아래 그림자, 얇은 푸른 rim.
PALETTE: #1A2A44 바다, #121C30 그림자. UI 통합 배경은 #0C131D, 별도 거점은 #FE984D.
BACKGROUND / INTEGRATION: isolated PNG alpha; 투명 배경의 지구 한 개만. 라벨과 점은 코드에서 별도 배치.
AVOID: 글자, 로고, 워터마크, 다른 천체, 바닥, 추가 장면, 강한 네온, 배경.

자연어 버전: 투명 배경에 지구 하나만 중앙 배치한다. 아시아, 극지 얼음, 흰 구름, 미세한 도시 불빛을 사실적인 위성 지형 느낌으로 표현한다. #1A2A44 바다와 #121C30 그림자를 사용하고 왼쪽 위에서 부드러운 빛을 비추며 가장자리에 얇은 푸른 빛을 더한다. #0C131D 화면에 통합할 수 있도록 여백을 둔다. #FE984D 거점과 모든 라벨은 코드에서 추가할 것이므로 이미지에는 포함하지 않는다. 글자, 로고, 다른 물체와 배경은 그리지 않는다.

gpt-image 사용 시 transparent_background 옵션을 함께 설정한다. 기타 모델은 alpha 지원 여부를 확인한다. 생성 프롬프트는 충실한 묘사이며 동일 이미지 재현을 보장하지 않는다. 통상 2–4회 반복이 필요하고, 실제 지리 정확성은 별도 확인해야 한다.

## 5. Consistency notes / Art direction QA

- 유지: 지구는 크게, 거점은 작은 주황색, 라벨은 지구 위에 얇은 짙은 박스.
- 유지: 영어 메타 정보에만 대문자·자간을 사용하고 국가명은 자연스러운 한글 표기.
- 유지: 지구 패널에만 대기광·궤도를 집중시킨다.
- 금지: 기존의 단색 청록 대륙·선명한 격자·큰 영문 국가명을 재도입하지 않는다.
- 금지: 주황색으로 대륙을 채우거나 모든 라벨 테두리를 강조하지 않는다.
- 금지: 큰 pill 라벨과 과도한 그림자로 관제 화면의 밀도를 바꾸지 않는다.

QA: 두 참고 이미지에서 밝고 어두운 섹션 교대나 마케팅용 pill은 관찰되지 않았다. 깊이는 짙은 라벨 표면·테두리와 약한 그림자로 만든다. 주황색은 거점/선택에 집중하고 파란색은 구면의 대기에 집중한다. 그라디언트는 장면 내부에 한정한다. 시스템 전체의 글꼴 굵기 상한이나 반응형 규칙은 이미지 2장만으로 확정하지 않는다.

| 항목 | 신뢰도 | 근거 |

| 대상·색상 방향 | ✅ | 두 첨부 이미지와 팔레트·픽셀 추출 |

| 동작 속도·hover·모바일 | ❓ | 정적 이미지에서 관찰 불가 |
| 재구성 레이아웃·반응형 | ⚠️ | 기존 대시보드에 맞춘 구현 결정 |

열린 사항: 원본과 동일한 텍스처·폰트는 확인되지 않았다. 현재 데이터에는 국가 필드가 없으므로 국가별 기사 매핑은 추가 요구와 데이터 설계가 필요하다. 현재 구현은 정적 지구 텍스처로 시각 방향을 재현하며 실시간 지구관측을 의미하지 않는다.
